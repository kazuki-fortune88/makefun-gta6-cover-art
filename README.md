Neon Coast Cover Studio — turn photos and captions into GTA 6-style multi-panel cover art, offline in the browser: five layouts, five gradient-map grades, per-panel crop, caption editing, undo/redo, and one-click export at 1080×1080, 1080×1350, 1920×1080 and story size.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 (use `--port <n>` for another port).
